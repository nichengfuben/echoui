## 二、严重错误防范

### [CRITICAL-001] 绝对禁止使用 pass 作为功能实现

**错误示例（立即删除）**:
```python
# 错误：pass 不是实现
async def save(self, user: User) -> None:
    pass

# 错误：注释说"TODO"也不行
async def find_by_id(self, user_id: UUID) -> Optional[User]:
    # TODO: 实现数据库查询
    pass
```

**正确做法**: 所有方法必须包含真实的业务逻辑。如果实现尚未完成，抛出 `NotImplementedError` 并附带详细说明，但这只允许在抽象基类中使用。

```python
# 正确：抽象基类中允许（且只在此处允许）
@abstractmethod
async def save(self, user: User) -> None:
    """保存用户实体。"""
    # 抽象方法无需实现体，raise NotImplementedError 由 ABC 机制保证
```

---

### [CRITICAL-002] 绝对禁止修改现有对象（不可变原则）

**错误示例**:
```python
# 错误：原地修改
def update_theme(config: ThemeConfig, new_color: str) -> None:
    config.primary_start = new_color  # 禁止

# 错误：修改传入的 dict
def process(data: dict) -> None:
    data["processed"] = True  # 禁止
```

**正确做法**: 永远返回新对象。

```python
# 正确：使用 dataclasses.replace 返回新对象
from dataclasses import replace

def update_theme(config: ThemeConfig, new_color: str) -> ThemeConfig:
    """返回更新了主色起始色的新主题配置。"""
    return replace(config, primary_start=new_color)

# 正确：返回新 dict
def process(data: dict[str, object]) -> dict[str, object]:
    return {**data, "processed": True}
```

### [CRITICAL-003] 链式方法必须返回 self

**错误示例**:
```python
# 错误：没有返回 self
def add_row(self, row: list[str]) -> None:
    self._rows.append(row)

# 错误：返回了其他值
def add_row(self, row: list[str]) -> list[str]:
    self._rows.append(row)
    return row
```

**正确做法**:
```python
# 正确：链式方法必须返回 self，且类型注解使用具体类名（Python 3.8 用字符串）
def add_row(self, row: list[str]) -> "TableBuilder":
    """追加一行数据（链式）。"""
    # 不可变：创建新行列表，不修改原列表
    self._rows = [*self._rows, row]
    return self
```

### [CRITICAL-005] 禁止使用 print 调试，禁止使用 f-string 格式化日志

**正确做法**:
```python
import logging

logger = logging.getLogger(__name__)

logger.info("用户创建成功: %s", user.id)
logger.error("用户不存在: %s", user_id)
```

```python
# 正确：严格 #RRGGBB 格式
renderer.render_text_ansi("Hello", "#FF0000", "#0000FF")
```

### [CRITICAL-008] 禁止在 normal_mode=True 时输出 ANSI 序列

**错误示例**:
```python
# 错误：没有检查 normal_mode
def render_text(self, text: str) -> str:
    return f"\x1b[38;2;255;107;107m{text}\x1b[0m"
```

**正确做法**:
```python
def render_text(self, text: str, start_color: str, end_color: str) -> str:
    """渲染文本。"""
    if self._normal_mode:
        return text  # normal_mode 下直接返回原文
    return self._apply_gradient(text, start_color, end_color)
```

### 3.3 函数规模限制（硬性边界）

```
单个函数/方法：不超过 50 行（含注释和空行）
单个类：不超过 400 行
单个文件：不超过 800 行
嵌套深度：不超过 4 层（if/for/with/try 的组合）
```

**超出限制时的处理方法**:
```python
# 嵌套过深时，提取私有辅助方法
# 错误示例（5 层嵌套）：
def process(data: list[dict]) -> list[str]:
    results = []
    for item in data:
        if item.get("active"):
            for sub in item.get("children", []):
                if sub.get("valid"):
                    try:
                        results.append(sub["value"].strip())
                    except KeyError:
                        pass
    return results

# 正确示例（最多 2 层嵌套，逻辑清晰）：
def process(data: list[dict]) -> list[str]:
    """处理数据列表，提取有效值。"""
    return [
        value
        for item in data
        for value in self._extract_valid_values(item)
    ]

def _extract_valid_values(self, item: dict) -> list[str]:
    """从单个数据项中提取有效值。"""
    if not item.get("active"):
        return []
    return [
        sub["value"].strip()
        for sub in item.get("children", [])
        if sub.get("valid") and "value" in sub
    ]
```

### 3.4 异常处理规则

```python
# 规则一：关键路径异常必须向上抛出，不得吞咽
async def get_user(self, user_id: str) -> User:
    try:
        user = await self._repository.find_by_id(user_id)
        if user is None:
            raise InputError(f"用户不存在: {user_id!r}")
        return user
    except InputError:
        raise  # 直接重抛，不包装
    except Exception as exc:
        logger.error("获取用户失败 user_id=%s: %s", user_id, exc, exc_info=True)
        raise AdapterError(f"获取用户失败: {exc}") from exc

# 规则二：非关键路径（如动画丢帧）可以捕获并记录
def _drop_frame(self, index: int) -> None:
    try:
        self._frames.pop(index)
    except IndexError as exc:
        logger.warning("丢帧 index=%d: %s", index, exc)
    # 继续执行，不抛出

# 规则三：UI 层捕获所有异常，显示友好提示
async def handle_request(self) -> None:
    try:
        await self._process()
    except EchoError as exc:
        self._notification.error(str(exc))
        logger.warning("框架异常: %s", exc, exc_info=True)
    except Exception as exc:
        self._notification.error("操作失败，请稍后重试")
        logger.error("未知异常: %s", exc, exc_info=True)

# 规则四：禁止捕获 BaseException（SystemExit、KeyboardInterrupt 不能被吞咽）
# 错误示例：
try:
    something()
except BaseException:  # 禁止
    pass
```

### 3.5 资源管理规则

```python
# 规则：所有资源必须通过上下文管理器管理

# 文件（正确）
from pathlib import Path

def read_config(path: Path) -> str:
    """读取配置文件。"""
    with open(path, encoding="utf-8", newline="") as file_handle:
        return file_handle.read()
    # 禁止在 with 块外使用 file_handle

# 数据库会话（正确）
async def save_data(session_factory: object, data: dict) -> None:
    """保存数据到数据库。"""
    async with managed_db_session(session_factory) as session:
        await session.save(data)
    # session 在此处已自动关闭

# 网络请求（正确）
async def fetch_data(url: str) -> dict:
    """获取远程数据。"""
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            response.raise_for_status()
            return await response.json()
```

```python
from echoui.core.exceptions import ConfigError


class TableBuilder(BaseComponent):
    """表格构建器组件，支持链式调用。

    Examples:
        >>> builder = TableBuilder(normal_mode=True)
        >>> output = (
        ...     builder
        ...     .set_headers(["ID", "名称"])
        ...     .add_row(["001", "张三"])
        ...     .add_row(["002", "李四"])
        ...     .render()
        ... )
        >>> "张三" in output
        True
    """

    def __init__(
        self,
        renderer: Optional[object] = None,
        normal_mode: bool = False,
        theme: Optional[object] = None,
    ) -> None:
        """初始化表格构建器。"""
        super().__init__(renderer=renderer, normal_mode=normal_mode, theme=theme)
        self._headers: list[str] = []
        self._rows: list[list[str]] = []
        self._alignments: list[str] = []

    def set_headers(self, headers: list[str]) -> "TableBuilder":
        """设置表头（链式）。

        Args:
            headers: 表头字符串列表，不能为空。

        Returns:
            TableBuilder: 返回 self 支持链式调用。

        Raises:
            ConfigError: 当 headers 为空列表时抛出。
        """
        if not headers:
            raise ConfigError("表头列表不能为空")
        # 不可变：创建新列表，不修改传入的列表
        self._headers = list(headers)
        return self

    def add_row(self, row: list[str]) -> "TableBuilder":
        """追加一行数据（链式）。

        Args:
            row: 行数据列表，长度必须与表头一致（如果表头已设置）。

        Returns:
            TableBuilder: 返回 self 支持链式调用。

        Raises:
            ConfigError: 当行数据长度与表头不一致时抛出。
        """
        if self._headers and len(row) != len(self._headers):
            raise ConfigError(
                f"行数据列数 ({len(row)}) 与表头列数 ({len(self._headers)}) 不一致"
            )
        # 不可变：展开创建新列表，不修改 self._rows
        self._rows = [*self._rows, list(row)]
        return self

    def set_alignments(self, alignments: list[str]) -> "TableBuilder":
        """设置每列对齐方式（链式）。

        Args:
            alignments: 对齐方式列表，每项为 "left"、"center" 或 "right"。

        Returns:
            TableBuilder: 返回 self 支持链式调用。

        Raises:
            ConfigError: 当对齐方式值非法时抛出。
        """
        valid = {"left", "center", "right"}
        for align in alignments:
            if align not in valid:
                raise ConfigError(
                    f"非法对齐方式: {align!r}，支持: {sorted(valid)}"
                )
        self._alignments = list(alignments)
        return self

    def render(self) -> str:
        """渲染表格为字符串。

        Returns:
            str: 渲染后的表格字符串，normal_mode 下不含 ANSI 序列。
        """
        from echoui.utils.text import get_display_width, pad_to_width

        all_rows = ([self._headers] if self._headers else []) + self._rows
        if not all_rows:
            return ""

        # 计算每列最大显示宽度（使用 get_display_width 处理 CJK）
        col_widths = [
            max(get_display_width(row[i]) for row in all_rows if i < len(row))
            for i in range(max(len(row) for row in all_rows))
        ]

        lines: list[str] = []
        for row_index, row in enumerate(all_rows):
            cells = [
                pad_to_width(
                    cell,
                    col_widths[i],
                    align=self._alignments[i] if i < len(self._alignments) else "left",
                )
                for i, cell in enumerate(row)
            ]
            lines.append(" | ".join(cells))
            if row_index == 0 and self._headers:
                # 表头分隔线
                separator = "-+-".join("-" * w for w in col_widths)
                lines.append(separator)

        return "\n".join(lines)
```

### 5.3 异步组件模式

```python
from __future__ import annotations

import asyncio
from contextlib import asynccontextmanager
from typing import AsyncGenerator, Optional

from echoui.components.base_component import BaseComponent


class Spinner(BaseComponent):
    """加载动画组件，支持异步上下文管理器。

    Examples:
        >>> import asyncio
        >>> spinner = Spinner(normal_mode=True)
        >>> async def demo():
        ...     async with spinner:
        ...         await asyncio.sleep(0.1)
        >>> asyncio.run(demo())  # 不抛出异常即为成功
    """

    def __init__(
        self,
        message: str = "加载中",
        normal_mode: bool = False,
        renderer: Optional[object] = None,
    ) -> None:
        """初始化加载动画。

        Args:
            message: 显示的消息文字。
            normal_mode: 降级模式开关。
            renderer: 渐变渲染引擎。
        """
        super().__init__(renderer=renderer, normal_mode=normal_mode)
        self._message: str = message
        self._running: bool = False
        self._task: Optional[asyncio.Task] = None

    def render(self) -> str:
        """渲染当前帧。"""
        return f"[...] {self._message}" if self._normal_mode else self._render_gradient_frame()

    def _render_gradient_frame(self) -> str:
        """渲染渐变动画帧（内部方法）。"""
        return self._renderer.render_text_ansi(
            f"... {self._message}",
            self._theme.primary_start,
            self._theme.primary_end,
        )

    def update_message(self, message: str) -> "Spinner":
        """更新显示消息（链式）。

        Args:
            message: 新的消息文字。

        Returns:
            Spinner: 返回 self 支持链式调用。
        """
        self._message = message
        return self

    async def start(self) -> "Spinner":
        """异步启动动画（链式）。"""
        self._running = True
        self._task = asyncio.create_task(self._animate())
        return self

    async def stop(self) -> "Spinner":
        """异步停止动画（链式）。"""
        self._running = False
        if self._task is not None:
            self._task.cancel()
            try:
                await self._task
            except asyncio.CancelledError:
                pass  # 此处 pass 合法：处理预期的取消异常
            self._task = None
        return self

    async def _animate(self) -> None:
        """动画循环（内部协程）。"""
        frames = [".", "..", "..."] if self._normal_mode else [".", "..", "..."]
        frame_index = 0
        while self._running:
            frame = frames[frame_index % len(frames)]
            print(f"\r{frame} {self._message}  ", end="", flush=True)
            frame_index += 1
            await asyncio.sleep(0.1)

    async def __aenter__(self) -> "Spinner":
        """异步上下文管理器入口。"""
        await self.start()
        return self

    async def __aexit__(
        self,
        exc_type: object,
        exc_val: object,
        exc_tb: object,
    ) -> None:
        """异步上下文管理器出口，确保动画停止。"""
        await self.stop()
```

### 8.2 语法兼容规则

```python
# 规则一：类型注解语法（3.8 兼容）
# 错误（3.10+ 语法，3.8 运行时报错）：
def func(x: int | str) -> list[dict[str, int]]:

# 正确（通过 from __future__ import annotations 支持）：
from __future__ import annotations  # 使注解变为字符串，延迟求值
def func(x: Union[int, str]) -> List[Dict[str, int]]:

# 或者（推荐：有 future import 后可直接写新语法，运行时不求值）：
from __future__ import annotations
def func(x: int | str) -> list[dict[str, int]]:  # 有 future import 时 OK

# 规则二：dataclass 参数（3.10+ 新增参数在低版本不可用）
# 错误（3.10+ 才支持 slots 和 kw_only）：
@dataclass(slots=True, kw_only=True)
class Config: ...

# 正确（3.8 兼容写法）：
@dataclass(frozen=True)  # frozen 是 3.7+ 的，安全使用
class Config: ...

# 规则三：内建集合泛型（3.9+ 才支持）
# 有 from __future__ import annotations 后，类型注解中可以写 list[str]
# 但运行时代码（如 isinstance 检查）仍需要用 List
from typing import List
isinstance(x, list)          # 正确（isinstance 不需要泛型）
isinstance(x, List[str])     # 错误（运行时不支持）
```

```python
    configure_platform()

# 规则：Windows 终端可能不支持 ANSI 序列（Windows Terminal 支持，cmd.exe 不支持）
# 检测方式：
import os
def is_ansi_supported() -> bool:
    """检测当前终端是否支持 ANSI 颜色序列。"""
    if sys.platform == "win32":
        # Windows Terminal / VS Code 终端支持
        return "WT_SESSION" in os.environ or "TERM_PROGRAM" in os.environ
    # Unix/macOS 默认支持
    return True

# 规则：Windows 路径中的 MAX_PATH 限制（260 字符）
# 使用 Path 时，超长路径在 Windows 上可能失败
# 解决方案：使用相对路径，或在 Windows 上启用长路径支持
```

## 十、常见混淆点速查

### 10.1 同名但不同职责的符号

| 符号名 | 所在模块 | 实际职责 | 容易混淆的原因 |
|--------|---------|---------|---------------|
| `render()` | `BaseComponent` | 抽象方法，返回组件字符串表示 | 每个组件都有，含义不同 |
| `render_text_ansi()` | `GradientRenderer` | 对文本应用渐变 ANSI 颜色 | 与 `render()` 名称近似 |
| `build()` | `BoxBuilder` | 返回渲染好的盒子字符串 | 不是 `render()`，是 `build()` |
| `State` | `echoui.core.state` | 响应式状态容器（泛型） | 不是 Python `state` 模块 |
| `Theme` | `echoui.core.theme` | 主题注册表（类方法工厂） | 不是 `ThemeConfig`（实际数据） |
| `ThemeConfig` | `echoui.core.theme` | 冻结数据类（具体主题数据） | 不是 `Theme`（注册表） |

## 十一、行为准则

### 11.1 任务执行原则

```
原则一：先理解再执行
  - 完整阅读任务描述，不得只看前几行就开始执行
  - 对不清晰的要求，先在脑中推演结果，确认理解正确再执行
  - 不得在任务开始前询问"需要我做什么"

原则二：实现完整性
  - 所有功能模块必须完整实现，不得遗漏任何功能点
  - 不得以"暂时省略"或"后续实现"为由跳过任何部分
  - 不得提交包含 TODO 占位符的功能代码（测试外的代码）

原则三：质量自检
  - 每次写完代码后，按本文档第一部分的检查清单自检
  - 发现问题立即修正，不等到提交才处理
  - 覆盖率不达标时，必须补充测试，不得降低要求

原则四：意外即记录
  - 遇到任何意外情况，立即记录到 AGENTS.md 的意外日志
  - 不得假装没有遇到问题
  - 不得在没有通知开发者的情况下悄悄绕过问题
```

### 11.2 与开发者沟通原则

```
情况一：遇到意外
  立即说明："我遇到了一个意外情况：{描述}。正在将其添加到 AGENTS.md。"

情况二：发现 AGENTS.md 条目过时
  说明："AGENTS.md 条目 '{标题}' 似乎已过时，因为 {原因}。正在更新。"

情况三：发现现有代码存在规范违反
  说明具体违反点，给出修正方案，不得假装没看见。

情况四：任务需求不明确
  说明具体的不明确之处，给出你的理解和假设，确认后再执行。
  不得在不确定的情况下随意选择一种实现。
```

### 11.3 禁止行为清单

```
[ 禁止 ] 使用 pass 作为功能实现

[ 禁止 ] 删除或覆盖用户的虚拟环境

[ 禁止 ] 在未理解完整需求时就开始执行
[ 禁止 ] 在发现问题时不通知开发者
[ 禁止 ] 提交覆盖率不达标的代码
```
