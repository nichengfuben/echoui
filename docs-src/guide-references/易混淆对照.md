# EchoUI 易混淆概念对照

> 两块 API 看起来相似、行为不同时，先确认左边还是右边。

---

## 范式与布局

| A | B | 区别要点 | 误用后果 |
|---|---|---------|---------|
| `flow` 布局 | `free` 布局 | flow 由布局引擎排布；free 用 `x/y/rotation/scale` 绝对坐标 | free 子节点坐标被忽略，或 flow 里误设 x/y 无效 |
| `Screen` | `Stage` | Screen 是整页/路由表面；Stage 是坐标空间 + 根容器 | 把游戏场景挂在 Screen 外，生命周期与相机跟丢 |
| `Sprite` | `role` | 一切皆 Sprite；role 只影响后端 primitive，不是平行类型 | 为每个 role 建子类体系，破坏单一范式 |
| `col/row` | `stage()` | 前者是 flow 容器；后者是 free 根 | 在 flow 页里直接摆绝对坐标而不嵌 free stage |

## 状态与事件

| A | B | 区别要点 | 误用后果 |
|---|---|---------|---------|
| `Store` | `signal()` | Store 持久响应式状态；signal 是一次性事件总线 | 用 signal 存业务状态；用 Store 做点击广播 |
| `@computed` | `effect()` | computed 返回值；effect 副作用无返回值 | 在 effect 里改依赖导致循环 |
| `batch()` | 无 batch | batch 合并同一 tick 内多次写入 | 多余 DOM/后端写入 |
| `@on("click")` | 原生 DOM 监听 | 统一事件模型，跨 target 归一化 | 绕过编译器，破坏 local-first 与 SSR 绑定 |

---

## 编译与产物

| A | B | 区别要点 | 误用后果 |
|---|---|---------|---------|
| `echoui build --target web` | `echoui dev` | build 产出可部署包；dev 带 HMR 服务 | 把 dev 服务器当生产部署 |
| `build --target static` | `build --target web` | static 无客户端水合 runtime；web 有轻量 runtime | static 页里期待客户端信号更新 |
| 运行时内省 IR | 全静态编译分析 | v0.1 用 mount 构建 IR；完整 AST 分析为后续能力 | 文档写「已完成静态分析」而实际没有 |
| SSR + resumable | 普通 hydration | resumable 不重建 DOM，只绑事件 | benchmark 显示 mutation 暴增 |

---

## 逃生层与扩展

| A | B | 区别要点 |
|---|---|---------|
| `raw.js` | `native_component()` | 一次性注入 vs 可复用包装 |
| `raw.dom` | `raw.html` | 回调操作节点 vs 插入 HTML 片段 |
| `bridge.web_api` | `bridge.os_api` | Web 沙箱 vs 桌面原生 |
| `Plugin @role` | 内建 `roles.py` | 插件扩展 vs 核心注册表 |

---

## 多端 target

| A | B | 区别要点 |
|---|---|---------|
| `desktop`（WebView 壳） | `gui`（Qt 控件树） | 视觉与 web 一致 vs 原生控件 |
| TUI `free` 模式 | Web `free` 模式 | 终端栅格降级 vs GPU/Canvas |
| Android webview 壳 | iOS 本地构建 | 本机可编 apk vs 需 macOS/CI |

---

## 持续订阅类问题

| 现象 | 根因 | 正确做法 |
|------|------|---------|
| 改了 `Store` 界面不更新 | 未走 reactive | 经 Store/reactive 写入 |
| 条件只判断一次 | 缺少订阅 | `@computed` / `effect` / 模板绑定 |
| Router guard 死循环 | guard 互跳 | 单测覆盖 guard 返回值 |
| 逃生层不跟 signal 变 | 未注册 reactive 回调 | 见 `examples/05_escape_layer` |
